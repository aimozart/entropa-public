# Entropa: open-source model

**Apache-2.0 for the code, CC-BY-4.0 for the documentation. A full giveaway.** Use it, change it, sell it. Keep the copyright notice; there is no warranty and no liability (Apache-2.0 sections 7 and 8). The project is paid for by custom work: setup, architecture review, attack tests and training. Decided 2026-11-17.

- **Code:** Apache-2.0 (see `LICENSE` and `NOTICE`). The crates already published under MIT (`entropa-core`, `entropa-node`) stay MIT as published; see `LICENSE-MIT`.
- **Documentation:** CC-BY-4.0.
- **Contributions:** DCO sign-off (no CLA); open after the first full release. Forks are always welcome.
- **The name:** "Entropa" is not licensed by Apache-2.0 (section 6): forks must rename.
- **What is never published:** private keys and credentials, licensed third-party standards text (for example PCI DSS), and the sealed test sets that keep our measurements honest (their results are published, failures included, at https://results.entropa.space).
- **Where the code is:** the production source is being released in stages as a clean export; documents and measurements are already at https://docs.entropa.space and https://results.entropa.space.

The earlier open-core split described in older versions of this file (open cryptography, proprietary product logic) is retired.
